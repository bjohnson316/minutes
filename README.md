# Minute Taker

Record meetings, transcribe them live, get a summary with decisions and action items, and export to PDF or PowerPoint.

Live at https://bjohnson316.github.io/minutes/

- Recordings, transcripts and summaries are stored only in your browser.
- AI summaries use your own Claude API key (Settings). Without one, a quick on-device summary is made instead.
- Live transcription works best in Chrome, Edge or Safari over https.
